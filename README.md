# PIXEL RALLY 8 — 8位像素拉力

一款 8-bit 像素艺术风格的 3D 街机驾驶游戏。在燃油与耐久耗尽之前,穿越随机生成的
**荒漠 → 山谷 → 城市** 无尽赛道,躲避障碍、管理车重与油量、寻找隐藏加油站。

纯浏览器运行,无需构建、无需联网(Three.js 已本地化)。

## 运行

直接双击 `index.html`(推荐 Chrome / Edge / Firefox)。

## 玩法

- **燃油 FUEL**:随时间/油门消耗,车越重越耗油,越野额外耗油。耗尽即失败。
- **耐久 BODY**:撞障碍、刮墙扣耐久,归零即撞毁。
- **车重 WT**:升级与货物都会加重车身,降低加速、增加油耗 — 车库中需权衡。
- **加油站**:沿公路周期性出现,低速驶入自动加油并小修;**隐藏加油站**(黄色 ? 招牌)
  远离路面,发现奖励 15 币。油量低于 45% 时 HUD 出现 ⛽ 指引箭头。
- **货物 CARGO**:木箱 +60kg,运到任意加油站换 5 币/箱(最多 5 箱)。
- **拾取物**:金币 / 油桶 +30 / 扳手 +25。
- **车库**:8 种涂装 + 4 系升级(引擎/油箱/装甲/轮胎,各 5 级),金币与最佳纪录
  存于 localStorage。
- **生态**:荒漠(开阔、可越野)→ 山谷(峡谷夹壁、弯急)→ 城市(黄昏、楼群路障),
  每种生态有独立 BGM 与调色。

## 技术要点

- **渲染**:Three.js r128(本地 `lib/three.min.js`),内部 426×240 低分辨率渲染 +
  `image-rendering: pixelated` 整数放大,NearestFilter 像素纹理,CRT 扫描线/暗角。
- **纹理**:全部 Canvas 程序化生成(公路/沙地/草地/混凝土/楼宇亮窗/招牌)。
- **世界生成**:种子化 RNG,分段弯道演化,对象池复用(仙人掌/岩石/楼/路障/拾取物),
  滑动窗口只保留车后 10 段至车前 75 段。
- **音频**:Web Audio 全程序化 — 方波/三角波 4 通道 BGM 音序器(标题/荒漠/山谷/城市
  四段循环)、引擎转速音、漂移与越野噪声、碰撞/拾取/加油等 8-bit 音效。
- **物理**:街机模型 — 前/侧向速度分解、抓地力指数衰减、手刹漂移、车重因子
  影响加速与油耗、越野阻力。
